# LaravPet-aas

LaravPet-aas — это проект из серии работ '-aas'. Проект предстваляет собой API для тамагочи. Он на стадии разработки, также планируется фронтенд часть. 

---

## Технологии

- **Backend:**
    - PHP 8.3
    - Laravel 13
    - MySQL
- **Архитектура Laravel:**
    - Eloquent ORM
    - API Resources
    - FormRequest
    - Middleware
